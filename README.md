# 🌏 股市村

可愛遊戲風的世界股市地圖：每個國家一隻 3D 小動物 + 城市旗幟（國旗、指數點數與漲跌），開盤的動物會在國內地形上四處走動，休市的會懶洋洋地散步、停下來就睡覺 💤（系統開啟「減少動態」時也會停止走動）。
版面仿 Google 地圖：地圖上方是可橫向捲動的篩選膠囊。左半（全球 / 亞太 / 美洲 / 歐洲 / 中東非洲）只顯示股票，點區域會依該區市場位置自動放大；右半（🛢️ 商品 / 💵 匯率 / 💹 經濟數據 / 🏦 債券 / 🏛️ 利率 / ⚔️ 地緣）只顯示對應主題的卡片，卡片內的列依重要程度排序（第一列最重要），色帶用第一列的漲跌上紅 / 綠（地緣卡片看狀態），卡片樣式和股市旗幟相同，標題是國家，電腦版放在各自國家附近（空間夠時卡片連字型整體放大，最多 1.7 倍，取「所有卡片都放得下」的最大倍率，見 `app.js` 的 `TOPIC_SCALE_MAX`；卡片離國家太遠時寧可縮小，見 `TOPIC_NEAR`），手機版排成左右兩欄。**經濟數據卡片**不顯示「成長 / 物價 / 就業」分隔標題（`markets.json` 的 `sec` 列仍保留，只用來分組），每個區塊用不同底色（藍 / 琥珀 / 紫 / 青，區塊內不分單雙列，見 `style.css` 的 `.rbg.g0`～`.g3`），字級盡量放大：電腦版上限 `TOPIC_SCALE_MAX_ECON`（2.2 倍）、離國家距離上限 `TOPIC_NEAR_ECON`，手機版上限 1.4 倍並以 iPhone 16（393×852）一頁看完為準；名稱和數值同列放不下時，先縮名稱（最小 8px），再縮數值。央行與白宮的建築圖示、地緣的動畫圖示（休戰的和平鴿、衝突的交擊雙劍）不論哪個篩選都留在地圖上。股市地圖的任何篩選，地圖上都會演出三則地緣新聞的動畫（`site/geoscenes.js`），動畫隨卡片的 `tone`（`ok` 緩和 / `warn` 緊張 / `bad` 衝突）改變：美伊衝突是油輪沿波斯灣、荷莫茲海峽、紅海航道行駛，局勢緊張時船變少變慢、船身變色，衝突時在海峽前排隊停下、偶爾放行，並遭飛彈攻擊起火；俄烏戰爭是雙方無人機飛向油庫、命中後爆炸起火冒煙，停火時改成白旗；美中貿易是貨櫃船經過收費站繳關稅，休戰時柵欄大多抬起、只收一點，升高時停很久、收很多。航線都是經緯度折線（已用 50m 陸地資料驗證不穿過陸地）。網址加上 `#fx`、`#geo`、`#asia` 這類片段可以直接開在指定篩選。最左側是直式圖層列（手機版在底部），主選單共四項：📈 總體經濟（目前的指數地圖）、📊 個股、💼 持倉、⚖️ 資產負債；目前只有「總體經濟」可用，其餘三項先放好位置，標示「即將」。旅遊地圖已拆成獨立專案 `Mapverse-Travel`（與本專案同層的資料夾）。

股市地圖的台灣島上蓋著台股市值前十大公司的建築（`site/corps.js`）：縮小時前 3 大（台積電、聯發科、台達電）合成一座小城市；放大到台灣夠大時，10 棟建築各自蓋在公司總部所在地並掛上招牌。建築跟著台股加權指數變化：上漲亮燈、下跌變暗，漲超過 2% 放煙火，跌超過 2% 烏雲打雷下雨。建築造型參考模擬城市 4 封面（細長玻璃高樓、層層退縮、斜切或尖頂樓冠、塔吊、停機坪），各公司商標直接嵌在大樓正面上方（商標圖在 `site/corp-logos.js`，沒有商標圖時顯示公司名稱）。市值與總部資料的備用值寫在 `corps.js` 的 `CORPS`；市值與名次平常由 iKDx-realtime 的 `tw-top.json` 每天自動更新。

開啟網頁時預設顯示「全球」。依開盤時間自動選區域（台股開盤選亞太、美股開盤選美洲，其餘看開盤中最重要的市場）的邏輯還在，預設關閉：把 `app.js` 的 `AUTO_REGION_DEFAULT` 改成 `true`，或網址加 `?auto=1`（`?auto=0` 強制關閉），或在瀏覽器 console 執行 `localStorage.setItem('autoRegion', 'true')` 就會啟用。網址加 `#asia` 這類片段仍可直接開在指定篩選。

**全部免費**：Cloudflare Pages 託管網頁，行情資料由 [iKDx-realtime](https://github.com/kobe-cht/iKDx-realtime) 統一抓取並發佈（Yahoo Finance、CNBC、證交所等來源，多來源備援），本專案沒有伺服器、沒有爬蟲、沒有 API key。

## 資料從哪來

本專案**只有前端**。網頁載入時直接讀 iKDx-realtime 發佈的檔案（網址在 `site/app.js` 的 `DATA_BASE`，預設 `https://ikdx-realtime.pages.dev/data/world/`，已開放 CORS）：

| 檔案           | 內容                                                       | 用在                         |
| -------------- | ---------------------------------------------------------- | ---------------------------- |
| `quotes.json`  | `markets.json` 所有代碼的報價（指數、商品、匯率、加密貨幣、公債殖利率） | 旗幟、主題卡片、概況卡       |
| `tw-top.json`  | 台股市值排行（證交所，收盤價 × 已發行股數）               | 台灣島上的前十大公司建築     |
| `fng.json`     | CNN 貪婪與恐慌指數（0～100、分級、前一日 / 一週 / 一個月 / 一年前的值） | 概況卡的情緒條               |

抓取由 iKDx-realtime 的 `fetch-world-realtime.yml` 負責（cloudflare-cron-worker 平日每 10 分鐘、週末每小時觸發），每個代碼依序嘗試多個來源，細節見該專案的 README。連不上資料來源時，股市頁顯示隨機的「演示資料」，台股建築沿用 `corps.js` 內建的市值。

## 部署步驟（Cloudflare Pages，約 5 分鐘）

1. Cloudflare Dashboard → **Workers & Pages → Create → Pages → Connect to Git**，選這個儲存庫（`17Kobe/Mapverse`）。
2. Production branch：`main`；Framework preset：`None`；Build command：留空；**Build output directory：`site`**。
3. **Save and Deploy**，完成後開啟 `https://<專案名>.pages.dev/`，手機用「新增到主螢幕」就像 App。

之後每次 push 到 `main` 都會自動重新部署。行情是網頁直接向 iKDx-realtime 讀取，**不需要**重新部署就會更新。

> 本機預覽（Windows）：直接雙擊 `start_local.bat`，或執行 `python scripts/serve_local.py`，開啟 `http://localhost:8000/`。不能直接雙擊 `index.html`，瀏覽器的 CORS 限制會擋掉 `markets.json`。
>
> 本地預覽（手動）：`cd site && python3 -m http.server 8000`。連不上行情來源時會顯示隨機的「演示資料」。
>
> 嵌入模式：網址加上 `?embed=1`（例如 `https://<專案名>.pages.dev/?embed=1`）只會顯示股市地圖，隱藏上方的概況卡（CNN 貪婪與恐慌指數、更新時間）與圖層列，適合用 `<iframe>` 嵌進其它網站（例如 iKDx 的「探索」分頁）。不加參數時一切照舊。

## 檔案結構

```
site/
  index.html  style.css  app.js   前端（d3 + SVG，無需構建）
  markets.json                    所有市場 / 指數 / 商品的設定（改這個就能增刪）
  corps.js  corp-logos.js         台灣島上的前十大公司建築與商標
  natives.js                      各國原住民小人（依主要指數漲跌歡呼 / 沮喪，目前只有台灣）
scripts/serve_local.py            本機預覽伺服器（8000 埠被占用時自動改用下一個埠）
```

## 常用修改

- **增刪指數**：編輯 `site/markets.json`。`type: "map"` 會出現在地圖上（要給經緯度、時區、交易時段）；`type: "bar"` 是商品、債券、匯率這類只抓行情、不上地圖的代碼，由 `topics` 的卡片引用；`type: "sub"` 是同一國家的其他指數（`of` 填主指數代碼、`abbr` 填旗幟上的短名），例如美國的那斯達克、道瓊、費城半導體，中國的深證成指、滬深300、創業板，台灣的櫃買，日本的 TOPIX，韓國的 KOSDAQ，香港的恆生科技。空間夠時旗幟會整張列出所有指數（電腦版畫面夠大時，旗幟連字型整體放大，最多 1.5 倍，且不能讓任何國家變成輪播、迷你或消失，見 `DESK_SCALE_MAX`；全球檢視很擠，上限 1.2 倍並容許最多 2 個國家退成迷你版，見 `DESK_SCALE_ALL`），不夠時每 4 秒輪播一個（右上角小圓點表示第幾個），點開卡片可用分頁切換。`s` 是 Yahoo Finance 的 symbol（Yahoo 沒有的指數與殖利率，其資料來源在 iKDx-realtime 設定）。**新增代碼後要到 iKDx-realtime 執行 `npm run sync-world`，補上該代碼的抓取來源再 push，否則網頁抓不到報價。**
- **台灣旗幟的市值前十大公司**：股市地圖放大到縮放倍率 ≥ 3（`app.js` 的 `EXTRA_K`，可在 `markets.json` 該指數加 `extraK` 覆蓋）時，台灣整張列出的旗幟會在加權 / 櫃買下面多一條藍綠色分隔標題「台股市值前十大」，接著列出十家公司的名次、名稱、股價與漲跌幅（資料來自 `tw-top.json`，超過 2% 一樣有醒目底色）。這個行為由 `markets.json` 的 `"extra": "corps"` 開啟，目前只有 `^TWII`。**電腦版點「亞太」「美洲」「歐洲」時不用放大**，該區有十大市值資料的國家（亞太：中日韓台印港；美洲：美加；歐洲：英德法）旗幟直接列出十大公司（`app.js` 的 `REGION_TOPS`）。公司名稱用較大的字級（`CORP_FS`），旗幟較寬（`LIST_W`）；國家旁邊擠不下時，電腦版會沿畫面找最近的空位，旗幟離國家太遠就畫一條虛線連回該國的動物。
- **台股前十大建築**：市值與名次由 `tw-top.json` 每天自動更新，名次變動時建築上的名次、大小自動跟著變，掉出前十的公司建築會收起來。排行中出現還沒設計過建築的公司時，只會列在詳情卡的清單；要幫它蓋建築，在 `site/corps.js` 的 `CORPS` 加一筆（代碼、名稱、總部經緯度與地址、品牌色、`kind`），並在 `ART` 加對應的造型。
- **主題卡片**：`site/markets.json` 的 `topics` 每一筆是一張卡片：`cat` 是篩選（`commodity` / `bond` / `rate` / `fx` / `geo` / `econ`），`short` 與 `flag` 是標題的國家，`lon` / `lat` 是放置的位置，`rows` 是列。有行情的列填 `s`（對應 `items` 的代碼）與 `l`（名稱），債券加 `"k": "y"`（以 bp 顯示變動），`calc` 可算兩個代碼的差（例如 10Y-2Y 利差）；手動維護的列填 `l` 與 `v`（數值），可加 `d`（和前期的差）、`tone`（`ok` / `warn` / `bad` 決定顏色），純文字說明用 `note`；`stamp` 是標題右側的資料期間。**經濟數據與六家央行利率是自動更新的**：列填 `e`（`econ.json` 的指標代碼，例如 `US_RATE`）與 `f`（顯示格式：`pct` / `idx` / `k` / `claims` / `amt` / `light` / `rate`），數值、前期與統計期間都來自 iKDx-realtime 的 `econ.json`，卡片標題右側的期間也取自它；`econ.json` 讀不到時顯示「--」（少數經濟數據列另有 `v` / `d` 備用值）。**地緣、白宮，以及聯準會卡片的「12月升息機率」是手動整理的，不會自動更新**，需要時直接改這裡。 **國界只畫有卡片的國家**：股票篩選（全球 / 亞太 / 美洲 / 歐洲 / 中東非洲）一律畫所有有股市的國家，主題篩選只畫該篩選所有卡片的國家；每個國家是光暈、亮色主線、中央白色細線三層。全球十大市值國家（`items` 有 `g10` 的市場）國界用紅色，其他用綠色，與漲跌無關。卡片的國家預設用 `flag` 找同一面國旗的股市國家；一張卡片對應多個或沒有股市的國家（歐元區、美伊衝突、俄烏戰爭、美中貿易）時，在卡片加 `countries`（ISO 3166 數字代碼陣列，例如 `[156, 840]`）。`landmarks` 是永遠留在地圖上的圖示（央行、白宮、地緣動畫），`card` 指向點擊後要開啟的卡片。
- **換動物**：改 `a` 欄位的 emoji。地圖上的 3D 動物圖放在 `site/assets/animals/`，對照表在 `app.js` 的 `ANIMALS`（含面向、走路方式）；沒有對應圖檔的 emoji 會直接顯示 emoji。國旗圖在 `site/assets/flags/`，依 `flag` 欄位自動對應。
- **小角色（海洋生物、船、各地人物）**：在 `app.js` 的 `CRITTERS` 加一筆，填圖檔、經緯度和動作 `mode`（`wander` 走動、`swim` 游、`whale` 噴水、`dolphin` 跳出水面、`boat` 划船、`surf` 衝浪、`ski` 滑雪、`chase` 追逐、`fin` 只露背鰭、拖著水痕在海面巡游（美國西海岸外海的大白鯊）、`flyfish` 飛魚（蘭嶼外海）、`still` 不動）。填 `deco: true` 的小角色（四川貓熊、俄羅斯棕熊、飛魚、大白鯊）可以和市場動物重疊，只有旗幟、卡片、介面擋到才收起來；這幾隻的圖是自繪 SVG（`assets/critters/panda.svg`、`brown-bear.svg`、`flying-fish.svg`），大白鯊的背鰭是 `critters/shark-fin.svg`。圖放在 `site/assets/critters/`（Fluent 3D）或 `site/assets/people/`（自繪 SVG：因紐特人、冰屋、維京長船）。會擋到市場旗幟時自動隱藏。
- **原住民小人（目前只有台灣）**：`site/natives.js`。該國主要指數（`market`）漲（≥ +0.15%）時，小人左右手交替高舉歡呼並原地蹦跳；跌（≤ −0.15%）時低頭哭泣、頭上下雨；平盤時散步、偶爾揮手、眨眼。漲跌超過 2% 時歡呼會撒彩帶、哭泣會打雷；休市時動作放慢；動畫關閉或系統要求減少動態時只擺一個靜態姿勢。要推廣到其他國家，在 `Natives.FOLK` 加幾筆（`market` 填該國主指數代碼、`lon`/`lat` 是位置、`ox`/`oy` 是組內的相對位置、`look` 選 `LOOKS` 的外觀或自訂顏色與頭飾），服飾請以該族群真實的傳統色彩與織紋為靈感，保持友善、不要刻板化。小人會自動避開旗幟，國家附近沒有空位時（例如手機版的雙欄旗幟）會移到畫面上最近的空地，並用虛線連回國家。
- **雲**：用 canvas 即時畫在 `#clouds`，固定在經緯度上，跟著地圖移動與左右循環，並隨西風慢慢往東飄。數量、風速在 `app.js` 的 `CLOUD_N`、`CLOUD_WIND`。關閉動畫或系統開啟「減少動態效果」時，雲和小角色都會停住。
- **紅漲綠跌 / 綠漲紅跌**：圖層列最下方的 ⚙️ 設定切換（預設紅漲綠跌）。
- **上帝視角的災難（股市地圖）**：在地圖上按右鍵（手機長按，或右下角的災難按鈕）選災難，預設「下雨」；選好後左鍵點地圖空白處就在那裡降下災難（點動物 / 旗幟仍是開詳情卡）。有下雨、冰雹、颱風、地震、海嘯、龍捲風、火山爆發、瘋狗浪、森林大火。效果畫在 `#fx` canvas、錨定經緯度跟著地圖移動，程式在 `site/disasters.js`：新增災難就在 `TYPES` 加一筆（icon、label、秒數），再到 `FX` 寫 `make`（產生粒子）與 `draw`（每幀畫）。`Disasters.active()` 可取得目前的災難，之後讓角色躲災難用。股市地圖的雙擊不再放大。
- **新增圖層**：在 `app.js` 的 `LAYERS` 加一筆（icon、label），完成後把 `ready` 設成 `true`。
- **區域縮放**：`app.js` 的 `REGION_MIN_K` 是區域檢視的最低放大倍率；整區放不下時，權重小的市場會留在畫面外，拖曳即可看到。
- **抓取頻率 / 來源**：在 iKDx-realtime 設定（cloudflare-cron-worker 的排程、`world_markets.json` 的來源順序），本專案不用動。

## 要知道的限制

- **遊戲風地形**（`site/terrain.js`）由瀏覽器即時繪製：AWS Terrain Tiles 的高度資料負責陸海、海深與山體光影，Esri 衛星影像只用來判斷沙漠 / 草原 / 森林 / 雪地，再套上遊戲調色盤；山脈以岩石色 + 雪線 + 光影直接畫在地表，並擺放手繪的樹與沙丘。需連網；右下角的資料來源標示請保留，商業用途請先確認 Esri 授權。
